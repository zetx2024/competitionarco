Matching Rules


    

  • Leading and trailing spaces are ignored.
    • 

  • Repeated spaces are normalised.
    • 

  • Matching is case-insensitive.
    • 

  • Unicode and accented characters are preserved and supported.
    • 

  • The primary match uses Name + Category + Country + School.
    • 

  • If that does not uniquely match, Name + Category + Country is attempted.
    • 

  • Existing participant IDs are preserved.
    • 

  • Participants without XLSX data receive "selected": "NO DATA".
    • 

  • XLSX-only records are retained with "participant_id": "NO DATA".
    • 

  • No participant data is uploaded to a server.
