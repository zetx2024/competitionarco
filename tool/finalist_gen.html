Output Rules


    

  • Every output entry contains only id, category, name, school, country, and selected.
    • 

  • If a JSON participant and XLSX row match, the XLSX information is used and the participant's existing participant_id is preserved.
    • 

  • If a participant exists only in participants.json, it is still included.
    • 

  • If an XLSX participant exists only in the XLSX, it is also included.
    • 

  • If a record has no value for a field, that field is "NO DATA".
    • 

  • Matched records are always placed first. Unmatched records are placed after all matched records.
    • 

  • If an included record has no participant ID, a new ID is generated.
    • 

  • Generated IDs use Year-J/S-Number. Junior = J, Senior = S.
    • 

  • The number is global across Junior and Senior; it does not restart for either category.
    • 

  • The next number is based on the highest numeric suffix already present in the existing participant IDs.
    • 

  • Matching is Unicode-safe and handles extra spaces, case differences, accents, Spanish/Latin names, Bangla, Arabic, and other multilingual text.
    •
