Output Format

        

            The generated JSON contains only six fields:
        


        
    
            
  • id = existing participant_id from participants.json
    • 
            
  • category
    • 
            
  • name
    • 
            
  • school
    • 
            
  • country
    • 
            
  • selected
    • 
        


        

            A participant found in the XLSX receives the XLSX values and its
            Selected value.
        


        

            A participant not found in the XLSX remains in the output with
            "selected": "No".
        


        

            XLSX-only people who do not exist in participants.json are
            not added, because there is no valid participant ID
            for them.
        


        

            Spaces, capitalisation, Unicode characters, Spanish/Latin names,
            accented characters, Bangla, Arabic and other multilingual text
            are handled safely.
